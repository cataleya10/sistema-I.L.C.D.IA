# raw/ine — Documentos INE originales

Coloca aquí los archivos originales (PDF o imagen) de Credencial para Votar.

**Formatos aceptados:** `.pdf`, `.jpg`, `.jpeg`, `.png`

**Convención de nombre:** `ine_<id_unico>.pdf`  
Ejemplo: `ine_001.pdf`, `ine_002.jpg`

> Después de agregar un archivo aquí, crea su par en `labeled/ine/<mismo_nombre>.json`
