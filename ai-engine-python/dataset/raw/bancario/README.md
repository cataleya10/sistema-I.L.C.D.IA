# raw/bancario — Estados de Cuenta y Comprobantes Bancarios originales

Coloca aquí los archivos originales (PDF) de Estados de Cuenta o carátulas bancarias.

**Formatos aceptados:** `.pdf`, `.jpg`, `.jpeg`, `.png`

**Convención de nombre:** `bancario_<id_unico>.pdf`  
Ejemplo: `bancario_001.pdf`, `bancario_002.pdf`

> Después de agregar un archivo aquí, crea su par en `labeled/bancario/<mismo_nombre>.json`
