# raw/nomina — Recibos de Nómina originales

Coloca aquí los archivos originales (PDF) de Recibos de Nómina / Comprobantes de Pago.

**Formatos aceptados:** `.pdf`, `.xml` (CFDI complemento nómina)

**Convención de nombre:** `nomina_<id_unico>.pdf`  
Ejemplo: `nomina_001.pdf`, `nomina_002.xml`

> Después de agregar un archivo aquí, crea su par en `labeled/nomina/<mismo_nombre>.json`
