# raw/curp — Documentos CURP originales

Coloca aquí los archivos originales (PDF o imagen) de Cédula de CURP.

**Formatos aceptados:** `.pdf`, `.jpg`, `.jpeg`, `.png`

**Convención de nombre:** `curp_<id_unico>.pdf`  
Ejemplo: `curp_001.pdf`, `curp_002.jpg`

> Después de agregar un archivo aquí, crea su par en `labeled/curp/<mismo_nombre>.json`
